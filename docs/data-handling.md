# 数据与分享

仓库已由所有者改为公开，包含所有者选择公开的历史营收、成本测算、预算、创作者内容和方案。任何访问者可浏览或下载；本次同步继续排除原始客户和登录资料。分享[仓库首页](https://github.com/g17326050972-dotcom/dewu-operations-sop)或[最新ZIP](https://github.com/g17326050972-dotcom/dewu-operations-sop/archive/refs/heads/main.zip)即可，链接不随更新改变。

原始订单、售后、结算和货盘只放在本地 `data/private/` 等被忽略目录中。工作配置命名 `sources.local.json`。`.gitignore` 同时忽略 Excel、凭据常用文件、环境文件、虚拟环境和生成输出。

Git 忽略规则只是防止误添加；提交前仍要检查 `git diff --cached`。不能将密码、Cookie、令牌、设备登录验证码、收货信息或后台全量导出放进 JSON/CSV、日志或文档。公开商品图与已公开内容链接可以作为报表证据。

报告网页和代码仓库分别发布。直接浏览日报/周报使用首页的报告链接；在GitHub中打开HTML文件主要看到源码。仓库的可见性不会自动替代报告站点的访问设置，也不保证中国大陆网络访问。
