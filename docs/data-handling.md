# 数据与分享

仓库设置为私有，包含历史营收、成本、预算、创作者公开内容及内部方案。分享时使用 GitHub 协作者权限；仓库链接不等于公开网页。

原始订单、售后、结算和货盘只放在本地 `data/private/` 等被忽略目录中。工作配置命名 `sources.local.json`。`.gitignore` 同时忽略 Excel、凭据常用文件、环境文件、虚拟环境和生成输出。

Git 忽略规则只是防止误添加；提交前仍要检查 `git diff --cached`。不能将密码、Cookie、令牌、设备登录验证码、收货信息或后台全量导出放进 JSON/CSV、日志或文档。公开商品图与已公开内容链接可以作为报表证据。

如要公开某份报告，单独发布已检查的静态站点目录，并验证未登录时可打开以及目标网络可达。GitHub 私有仓库不会自动替代原报告发布站点，也不保证中国大陆网络访问。
