# 新品上架

入口：[新品上架技能](../../skills/dewu-jewelry-new-product/SKILL.md)。批量草稿、界面恢复等资料随技能保存在 `references/`。

输入：最新货盘、目标货号清单、对应的真实商品图和规格资料。先核对材质、类目、标题、属性、尺寸及礼盒，再建草稿与已有预出价，逐项回读。提交审核及发布按当次用户授权执行。

后续：[货品池编码](../merchant-pool-code/README.md) → [自建折扣](../self-discount/README.md)。本仓库未复制原项目的整批商品图片和原始货盘；执行时从本地授权素材补齐。

最近完成记录（2026-10-12）：YX9641001、YX9641002、YX9641003、YX9637001、YX9642001均保存为草稿并回读，未提交审核。该批按用户确认使用三个礼盒规格、库存各1、新版轻奢详情页，链长按资料核实为40–44cm区间。此批参数不能直接套用到其他商品；尺码区间仍按实际资料填写。
