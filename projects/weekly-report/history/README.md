# 周报历史入口

`python3 scripts/build-history.py --output site` 将 `weekly-archive/` 中已公开的周报生成到 `site/`，无第三方构建依赖。站点根路径默认最新一期，每期固定路径为 `reports/<期号>/`，选择器与历史表均可切换。

新增一期时，将审核过的公开页面及其本地资源放入 `weekly-archive/pages/<期号>/`，在 `weeks.json` 添加汇总指标、查询日期和核对口径，再重建。不要将原始订单、成本工作簿、登录态或凭据加入归档。缺失指标使用 null，不能填写 0。

当前4期：20260831-0906、20260907-0913、20260921-0927、20261005-1011。9月7—13日仅完成两笔已知关闭订单修正；其他数据质量差异在历史表逐项标注。新加入的选择器不改变原始页面业务数据。


公开入口：https://dara-weekly-20260831.lucky-fawn-8231.chatgpt.site/

在本目录执行 `python3 -m http.server 8000 --directory site`，打开 http://127.0.0.1:8000/ 浏览。可将 `site/` 上传到任意静态托管平台；网页使用相对路径，也支持子目录部署。
