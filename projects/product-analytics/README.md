# 商品数据分析

入口：[商品分析技能](../../skills/dewu-product-analytics/SKILL.md)。日报限定一级类目“流行饰品/眼镜/服配”，持续跟踪头部款、新款、流量、转化、渠道及引力内容。

当前公开入口：[得物商品每日趋势](https://dewu-product-daily-trends.lucky-fawn-8231.chatgpt.site/)。本次归档最新已发布版本为10月14日第8版，经营数据截至10月13日，文件见[静态页面](examples/2026-10-14/site/index.html)及[发布记录摘要](examples/2026-10-14/publication.json)。

该版覆盖28款、333条可用经营日记录，保留59条历史缺口；23款来源共322条渠道日记录，5款确认无来源入口；28款84个人群年龄画像、5条引力内容57条真实日值。2款经营PV与来源PV不一致，保留两处原值及差异。底表和覆盖说明随页面保存。

10月14日新增规范：得物推单品仅采截至昨日近7个完整自然日的每日明细和趋势，不做日环比、上周同日或周环比，不采额外对比期。此要求已更新到仓库技能；第8版尚无完整独立得物推明细，本次归档没有补造该数据。经营、来源和引力仍沿用既定对比要求。

后台同口径区间总量明确为0、且可据此确定日值的字段，保留区间证据直接覆盖日零值，不逐天重复查看。“—”和未获取仍留空；无访客时转化率不写成0。

`examples/2026-10-12/draft-site/` 保留首次归档时的旧草稿，作为历史快照。它当时的站点权限阻碍与数据缺口不代表最新日报状态。

`work/` 保存采集结果整理、每日构建、周对比、趋势图和验收脚本，本次补入10月13日、14日的12个脚本；`channel-component/` 与 `comparison-component/` 为页面组件。历史生成器仍含原项目路径及未入库输入，执行前检查。已有最终数据时不要重新运行 `consolidate_20261014.py` 或 `checkpoint_20261014.py` 覆盖成中间状态。部分工作簿生成器需要Codex的`@oai/artifact-tool`。

可独立验证本次静态示例：

```sh
node projects/product-analytics/work/validate-daily-1014.mjs projects/product-analytics/examples/2026-10-14/site/index.html
```

保留汇总 JSON/CSV 和页面；不包含后台原始 AX 快照、客户订单、登录态、达人联系方式或整份协作明细。运营建议应基于同范围、同时间口径，后续行动单独进入[优化落地](../action-plan/README.md)。
