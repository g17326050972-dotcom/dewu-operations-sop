# 商品数据分析

入口：[商品分析技能](../../skills/dewu-product-analytics/SKILL.md)。日报限定一级类目“流行饰品/眼镜/服配”，持续跟踪头部款、新款、流量、转化、渠道及引力内容。

`examples/2026-10-12/draft-site/` 保存 10 月 12 日**本地草稿**，打开 `index.html` 可查看页面。`coverage.json` 记录数据覆盖和缺口：部分新品缺少历史日数据，上一周部分渠道记录尚未补齐，原站点编辑权限也存在阻碍。没有数据的位置保持缺失，不能改成 0；此草稿未确认成功发布。

`work/` 保存采集结果整理、每日构建、周对比、趋势图和验收脚本；`channel-component/` 与 `comparison-component/` 为页面组件。它们仍含原项目路径和未入库数据依赖，需按当前输入调整后执行。部分工作簿生成器需要 Codex 的 `@oai/artifact-tool`。

保留汇总 JSON/CSV 和页面；不包含后台原始 AX 快照、客户订单、登录态、达人联系方式或整份协作明细。运营建议应基于同范围、同时间口径，后续行动单独进入[优化落地](../action-plan/README.md)。
